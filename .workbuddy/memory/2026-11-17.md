## 20:40 加了一键脚本 scripts/deploy.ps1（用户问「怎么手动部署」）

- 脚本 4 步：检查 node → 缺依赖才 `npm install` → 检查 `wrangler whoami`（未登录自动拉 `wrangler login`）
  → `npm run build` → `wrangler deploy` → 打印房间链接。实测两次跑通，EXIT=0，输出
  `Deployed kokospace triggers (1.04 sec)` + URL。
- **踩了两个坑**：
  1. `.ps1` 存成 **UTF-8 无 BOM** 时，PowerShell 5.1 按 GBK 解析中文 → `ParserError: UnexpectedToken`。
     修法：`[System.IO.File]::WriteAllText($f, $c, (New-Object System.Text.UTF8Encoding($true)))`。
     （用 Write 工具写完 .ps1 都要补这一步，否则必挂。）
  2. `$ErrorActionPreference='Stop'` + 原生命令往 stderr 写东西（wrangler 的代理告警）会被当成
     terminating error 直接中断脚本。改成 `'Continue'` + 自己判 `$LASTEXITCODE`；读输出用 `2>$null` 吞掉告警。
- 提交 `feat: 加一键手动部署脚本 scripts/deploy.ps1`（850e832），本次部署也顺手刷新了线上版本。
